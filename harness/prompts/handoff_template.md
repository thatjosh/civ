# Handoff template

The five headings, in this order, each bare (no suffix after the heading text):

## State of work
The task you hold (its id and thread), what is finished, what is half done, and where the result file stands.

## Open threads
Board seqs you were reading or replying to, with one line each on why they matter.

## What to try next
The next concrete step, then one retrospective line: what you would have done differently from the start.

## What not to retry
Approaches that failed, with the reason, so the successor does not repeat them.

## Files worth reading
Paths under your directory (work/ and notes/) and what each holds.
